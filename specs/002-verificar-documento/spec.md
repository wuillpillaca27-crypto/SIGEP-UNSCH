# Verificación pública de documentos

- FR-001. Cualquier persona puede consultar un código o un enlace QR de la página de verificación sin iniciar sesión.
- FR-002. Solo un registro emitido confirma el documento. Un expediente aprobado, anulado o inexistente y una consulta con tipo incompatible no producen una confirmación.
- FR-003. El resultado público muestra el código, el tipo, el programa y la fecha de emisión si está registrada. La respuesta excluye datos personales y archivos.
- FR-004. La interfaz distingue código inválido, documento no encontrado e indisponibilidad de la API. Una nueva consulta elimina el resultado anterior.
- FR-005. La base local tiene un registro de demostración explícitamente identificado para comprobar el recorrido, sin alterar los expedientes existentes.
