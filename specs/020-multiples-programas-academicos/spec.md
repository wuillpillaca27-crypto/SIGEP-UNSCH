# Múltiples programas académicos
Una cuenta estudiante puede tener matrículas únicas por programa, cada una con código, estado, fechas y habilitación. El asistente y el panel privado muestran únicamente sus matrículas. Cada borrador y expediente queda asociado al registro seleccionado. Las matrículas suspendidas, retiradas, futuras o deshabilitadas no permiten solicitudes nuevas ni presentar borradores.
La administración asigna o actualiza matrículas y la semilla prepara cuentas individuales y una cuenta multirregistro para desarrollo.
