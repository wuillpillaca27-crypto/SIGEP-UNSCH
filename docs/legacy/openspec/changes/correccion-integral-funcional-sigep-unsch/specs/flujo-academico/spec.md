## ADDED Requirements
### Requirement: Configurar y validar el flujo académico
El sistema SHALL aplicar publicación y habilitación del programa, titularidad de matrícula y autorización académica expresa al revisar y aprobar.
#### Scenario: Solicitud y revisión en desarrollo
- **WHEN** una cuenta de demostración habilitada presenta una solicitud y un operador coteja sus requisitos
- **THEN** el expediente queda disponible para la autoridad autorizada y el sistema conserva su historial
